# LaunchPad — Student Project Planner

LaunchPad helps students turn a rough project idea into a focused MVP plan.

## Features
- Capture a problem statement and target audience
- Adjust the plan to skill level and available time
- Generate a milestone-based build sprint
- Copy the plan or download a Markdown README
- Responsive interface; no dependencies or API keys

## Run locally
Open `index.html` in a browser.

## Publish
Create a public GitHub repository, upload `index.html` and this README, then enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.

## Technical note
The current version uses transparent, rule-based planning logic. It does not call an AI model or transmit user inputs to a server. The project is intentionally scoped as a first MVP; a future version could add an LLM-backed planning assistant with user consent and secure server-side API handling.
